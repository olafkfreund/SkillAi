## How to read this

Every tool has a required **scope** (`read`, `write`, or `admin`). The scope hierarchy is `admin ⊃ write ⊃ read` — see [Scope hierarchy](/SkillAi/rest-api/authentication#scope-hierarchy).

Every tool flagged **write** also requires an explicit `confirmed: true` argument in the call. The MCP client (Claude Code, claude-desktop) prompts you inline before sending; the server rejects writes without confirmation. See [write-confirm flow](/SkillAi/mcp-server/connecting#the-write-confirm-flow).
