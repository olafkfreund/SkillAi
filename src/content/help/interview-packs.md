# Interview pack generation

An interview pack is a tailored question set the AI builds for one specific candidate against one specific role. Two packs for the same candidate against two different roles will look quite different — that's the point.

## When to generate a pack

Whenever a candidate moves from `shortlisted` to `interviewing`, you'll usually want one. Packs replace the "I'll wing it" interview model with: "here are six tailored questions, three of which probe gaps the AI noticed in the CV".

## Pack types

Choose one when you generate:

| Type | Purpose | Length |
|---|---|---|
| **Full** | Use as the live interview script. Includes role-specific deep dives, behavioural questions and (optionally) a code challenge. | 8–12 questions |
| **Pre-screening** | Shorter, lighter — for the first 20-minute call before the proper interview. Skips deep technicals, focuses on motivation, basic fit and red-flag-spotting. | 4–6 questions |

Pre-screening packs do not include code challenges, even if you tick the box. That's deliberate — they're for the "should we even talk to this person properly" call.

## Generating a pack

From the candidate detail page (when viewed in the context of a role):

1. Click **Generate interview pack**.
2. Pick **pack type** (full or pre-screening).
3. **Include code challenge?** — only available for full packs. Adds a tailored coding exercise, with starter code and grading rubric.
4. Pick the **language**. See language fallback below.
5. Click **Generate**. A progress bar appears. Generation takes 20–60 seconds.

When it lands, the pack opens in a viewer with each question on its own card. From there you can:

- Copy individual questions to clipboard.
- Export the whole pack as a PDF for a printed interview kit.
- Regenerate if the result wasn't useful — you'll get a different set.

## Language

Packs can be generated in any of the supported languages:

`en`, `pl`, `de`, `fr`, `es`, `it`, `pt`, `nl`, `cs`, `sv`

The language defaults are picked in this order:

1. The first entry in the candidate's `languagesSpoken` field that maps to a supported language. So a candidate marked as fluent in Polish gets a Polish pack by default.
2. The tenant's default pack language (set by your admin in **Settings**). See [Trusted hosts and language settings](/dashboard/help/settings-trusted-hosts-and-language).
3. English.

You can always override at generation time — the candidate's preference is the default, not a lock.

## What goes into a pack

The AI gets the role description, the candidate's parsed CV, and the most recent score with reasoning. From that it builds a question set that:

- **Probes the strengths.** Confirms the impressive things on the CV are real and the candidate can talk about them.
- **Probes the gaps.** If the AI flagged a soft area in scoring, you get a question that explores it.
- **Includes behavioural questions** mapped to the role's seniority and customer framework level.
- **Adds a code challenge** if requested — typically a 30–45-minute exercise sized to the seniority.

All of this is generated by Claude (or Gemini if configured). Generation is wrapped with retries and a hard timeout, so a flaky API call won't hang the UI forever. If generation fails, you'll see a **Retry** button.

## Tips

- **Generate the pack just before the interview**, not days in advance. Candidates sometimes upload an updated CV between booking and interview.
- **Don't follow the pack as a script.** Use it as scaffolding. The best questions are the ones that come from following up on what the candidate just said.
- **For pre-screening, ignore the questions and read the AI's `summary`** at the top — it's often enough to decide whether to book the full call.
